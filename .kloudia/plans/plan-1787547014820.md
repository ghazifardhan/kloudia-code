# Landing Page Implementation Plan (Static HTML + Tailwind CDN)

Build standalone static HTML landing page for Kloudia CLI using Tailwind CSS via CDN.

## Architecture & Tech Stack
- **Format**: Single static file `index.html`
- **Styling**: Tailwind CSS via CDN (`<script src="https://cdn.tailwindcss.com"></script>`)
- **Runtime**: None required (zero JS framework/server setup)

## Key Sections
1. **Hero**: Title, tagline, install badge (`npm i -g kloudia-code`), CTA button.
2. **Features Grid**: Multi-Agent Orchestration, Skills Engine, Interactive TUI, Session Persistence, Project Memory.
3. **Terminal Preview**: Styled mock terminal showing REPL & slash commands.
4. **Configuration**: Config file snippet (`~/.config/kloudia/settings.json`).
5. **Footer**: GitHub link and MIT license notice.

## Step-by-Step Execution
1. Create `index.html` at root directory.
2. Add Tailwind CDN script tag in `<head>`.
3. Build responsive UI layout with Tailwind utility classes.
4. Test directly in browser.
